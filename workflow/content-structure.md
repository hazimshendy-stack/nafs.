# Content Structure

Schema:
```
{id, type, title, subtitle?, content[], notes}
```

Content item types:
- `text`
- `list`
- `table` (headers + rows)
- `diagram` (lines)
- `quote`
- `callout` (variant: info | warn | danger | success)

Slide types: cover · content · list · table · diagram · quote · section · closing
